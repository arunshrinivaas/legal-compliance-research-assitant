# Python/FastAPI Reference Backend

This directory contains the original Python/FastAPI implementation of OpusLex.

This implementation is FROZEN and ARCHIVED.

The active backend is now the Java 21 + Spring Boot implementation in the separate Java repository.

This archived implementation is retained for:

- historical reference
- behavioral comparison
- migration traceability
- debugging/reference purposes

It is NOT part of the active application runtime.

Do not modify this implementation unless explicitly required for historical/reference analysis.
